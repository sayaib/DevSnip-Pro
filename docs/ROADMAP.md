# Roadmap

This is a list of directions being considered, not a promise or a schedule. Priorities follow what people actually use and ask for, so the most useful thing you can do is [open or upvote an issue](https://github.com/sayaib/DevSnip-Pro/issues).

## Recently shipped

- **11.73.1:** Get started guide and walkthrough, What's new card, Feature Explorer milestone, faster startup through lazy loading.
- **11.72.1:** Nine appearance themes for every DevSnip Pro panel; redesigned Milestones & Points.
- **11.71.1:** Database Client for PostgreSQL, MySQL, SQL Server, SQLite, MongoDB and Redis.
- **11.70.1:** Web and Mobile toolkits; every tool in one of 13 sections.

## Under consideration

**REST API Client**
- Import collections from OpenAPI and Postman files into saved collections.
- Run a whole collection with its assertions and show a pass/fail summary.

**Database Client**
- Export query results and tables to CSV and JSON files.
- An SSH tunnel option for databases that are not directly reachable.

**Security**
- A workspace audit summary that can be saved as a baseline, so later scans show only new findings.

**AI & LLM**
- Keep the model price and context-window table current with a clear "last checked" date.

**Experience**
- Make more tools fit narrow sidebars and small screens.
- Translate the interface text.

## Not planned

- **Accounts, cloud sync or a hosted backend.** DevSnip Pro stays local-first.
- **A public points leaderboard.** It would need a server and identifiable users, which goes against the privacy model.
- **Browser-only VS Code (vscode.dev).** Several tools need Node APIs.
