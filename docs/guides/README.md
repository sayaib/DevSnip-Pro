# DevSnip Pro guides

Task-first guides for everyday development work in VS Code. Each one answers a common question, then walks through it step by step with the free [DevSnip Pro](https://marketplace.visualstudio.com/items?itemName=sayaib.hue-console) extension. Most of the habits apply to any tool.

## APIs

- [How to test REST APIs in VS Code](test-rest-apis-in-vscode.md): first request, environments, collections, unhappy paths, code generation.
- [How to test a GraphQL API in VS Code](test-graphql-api-in-vscode.md): query, variables, operation name, auth, types from a schema.
- [Free Postman alternative in VS Code: which API client to use](postman-alternative-in-vscode.md): text-file vs GUI vs all-in-one clients, and what DevSnip Pro does not do.

## Databases

- [How to connect to PostgreSQL, MySQL, MongoDB and Redis in VS Code](connect-to-postgresql-mysql-mongodb-redis-in-vscode.md): connection strings, browsing and editing safely, the query console. SQL Server and SQLite too.

## AI and LLMs

- [How to count LLM tokens and estimate cost in VS Code](count-llm-tokens-and-cost-in-vscode.md): tokens and cost across models, prompt templates, parsing model output, RAG planning.
- [How to install and use OpenCode in VS Code](opencode-in-vscode.md): set up the agent, then check its work with deterministic tools.

## Security

- [How to find hard-coded secrets and security issues in VS Code](find-hardcoded-secrets-in-vscode.md): workspace, infrastructure, dependency and endpoint checks before a release.

## Everyday tools

- [Format JSON and YAML, decode JWTs and other quick developer tools in VS Code](format-json-decode-jwt-in-vscode.md): formatters, encoders, Git recipes, snippets and checked DevOps boilerplate.
