# AI & LLM tools

These tools run locally and need no API key:

- **LLM Models, Tokens & Cost:** estimate tokens and compare what a prompt costs across models.
- **Prompt Builder:** assemble system and user prompts with variables and examples.
- **LLM Output Cleaner & JSON Validator:** extract and validate the JSON an LLM returned.
- **JSON → TOON:** shrink JSON for prompts.
- **RAG tools** (in **Data & RAG**): test chunking, size an index, evaluate retrieval and check answers are grounded.

To call a model with your own key, use the REST API Client's AI providers, or the **LLM API Tester**.
