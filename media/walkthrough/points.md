# Track your progress

You earn points for using DevSnip Pro:

- **3 points** for most tool runs; security audits, snippets and AI tools earn more.
- **5 points** daily login, growing with your streak, plus a **10-point** daily boost you claim in the panel.
- **Daily quests:** three new goals every day, and a bonus chest when you finish all of them.
- **Milestone bonuses**, such as Tool Explorer, Weekly Warrior and Feature Explorer.

Points move you up the ranks, from Bronze to Grandmaster, unlock themes and badge frames, and pay for premium REST API Client tools such as load testing. Streak freezes keep your streak safe on a day you miss.

Tool runs count up to a daily limit and repeated runs of the same tool earn less, so points reflect real use rather than clicking.
