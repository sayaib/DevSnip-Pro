# Send your first API request

Try a public test API:

1. Open the **REST API Client**.
2. Keep the method as `GET` and enter `https://jsonplaceholder.typicode.com/todos/1`.
3. Press `Enter` or click **Send**.

The response shows its status, time, size, headers, cookies and a formatted body you can search, copy or save.

**Next steps**
- Add an environment with a `baseUrl` variable and use it as `{{baseUrl}}/todos`.
- Paste a cURL command into the URL bar to import it.
- Save the request to a collection, or generate code in JavaScript, Python, Go, Java or C#.
- Switch to **GraphQL** or **WebSocket** for those APIs.
